VISUALIA - INSTALADOR PARA WINDOWS

Producto: Visualia - Generador de Imágenes por Lote
Versión: 1.2.1
Autor: Nelson Sanchez Dillon

El instalador:
- muestra bienvenida y términos de licencia;
- permite seleccionar la carpeta de instalación;
- muestra el espacio requerido;
- crea accesos en Inicio y, opcionalmente, en el escritorio;
- registra la aplicación en Configuración > Aplicaciones;
- incluye desinstalador;
- permite abrir Visualia al finalizar;
- conserva la configuración personal durante actualizaciones.

La clave API se guarda en:
%LOCALAPPDATA%\Visualia\.env

El instalador no incluye ninguna clave privada.
