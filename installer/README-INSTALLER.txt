VISUALIA - INFORMACIÓN DEL INSTALADOR

Producto: Visualia - Generador de Imágenes por Lote
Versión: 1.4.4
Creador y editor: Nelson Sanchez Dillon

El asistente muestra primero el aviso de privacidad y las advertencias, y exige
confirmar que se leyeron. Después presenta el acuerdo de licencia, que también debe
aceptarse para instalar. Luego permite elegir la carpeta de destino y muestra el
progreso de instalación.

Visualia no incorpora analítica ni envía al creador fotografías, prompts, hojas de
cálculo, datos de clientes o claves API. Para generar imágenes, los archivos
seleccionados y el prompt se envían a OpenAI mediante la API, usando la clave del
usuario. Al iniciar, Visualia consulta GitHub para comprobar si hay actualizaciones.
Los servicios externos y proveedores de red pueden recibir los datos técnicos
normales necesarios para esas conexiones.

El instalador crea accesos en Inicio, ofrece un acceso opcional en el escritorio,
registra la aplicación en Configuración > Aplicaciones, incluye un desinstalador y
permite abrir Visualia al finalizar. La configuración personal se conserva durante
las actualizaciones.

La clave API se guarda localmente en:
%LOCALAPPDATA%\Visualia\.env

El instalador no incluye ninguna clave privada. Visualia muestra costos estimados;
el uso de la API puede generar cargos de OpenAI a cargo del usuario.
